                                INTER_LANCZOS4, INTER_NEAREST)

BUILD / EXECUÇÃO
=====================================================================
Python recomendado: 3.10 a 3.12 (desenvolvido e testado com Python 3.11.9).

1) (Opcional, recomendado) Criar e ativar um ambiente virtual
   Windows (PowerShell):
     python -m venv .venv
     .venv\Scripts\Activate.ps1
   Linux / macOS:
     python3 -m venv .venv
     source .venv/bin/activate

2) Instalar as dependências
     pip install -r requirements.txt

3) Executar a aplicação (abre em http://localhost:8501)
     streamlit run app.py

4) (Opcional) Executar os testes automatizados
     pip install -r requirements-dev.txt
     python -m pytest

5) (Opcional) Validar o pipeline com fotografias próprias
   Nenhuma fotografia externa é necessária para executar o projeto.
   Se quiser, coloque fotos em examples/real/ e execute:
     python examples/validate_real.py
   A tabela-resumo é gravada em validation_output/resultados.md

6) (Opcional) Regenerar as imagens sintéticas de exemplo
     python examples/generate_examples.py

Publicação (Streamlit Community Cloud): repositório no GitHub, app com arquivo
principal app.py, Python 3.11 ou 3.12. Não há segredos nem variáveis de ambiente.
